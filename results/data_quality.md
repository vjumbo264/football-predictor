# Data quality — blocked

No historical snapshot has been ingested or copied into this public repository. The [provider's data page](https://www.football-data.co.uk/data.php) describes use as intended for private individuals; permission to publicly cache the historical extracts for this project has not been verified. The mirror candidates did not establish a verified permission chain and full pre-close/close odds coverage. Consequently, no observed match counts or missing-odds percentages are presented. CI tests the parser against synthetic fixtures only.
