# Decisions

- This host does not require an applet; no front-end was created.
- The build brief in the repo is summarized and contains no credential values.
- Data access: no raw/public archival until upstream permission and suitable coverage are verified. The DataHub candidate has downstream PDDL but does not establish the required scope of prices or upstream permission; Kaggle and Footiqo did not establish a free exact replacement. Immutable authorized inputs can be parsed from disk; raw inputs and local run outputs are ignored by git.
- Chronological split: 2020/21–2022/23 burn-in, 2023/24 validation, 2024/25–2025/26 test, 2026/27 forward slice only if eligible. No observed test results were inspected.
- Prefer reliable Pinnacle for benchmarks; from 23 July 2025 exclude it per the provider's warning. Market average is a benchmark, not an executable price; simulation uses predefined named-book order with the same book's close, leaving missing close missing.
- One-vs-rest ECE averages across classes; Brier sums over classes for 1X2 and binary markets. Confidence intervals resample whole calendar weeks with all paired rows retained.
- Walk-forward uses per-league 14-day refits anchored to July 1 each season. Each fit and eligibility counts exclude the cutoff date. Require five previous matches per team available at the refit. Model grid has 21 variants; choose goal models by validation scoreline NLL and the other models by equal-market log loss. Prefer the first documented grid setting within 0.0001 nats of the current best.
- Betting grid: nine threshold pairs per candidate/model/market (90 planned combinations for four single models plus ensemble across two markets). One ticket per match/market (highest EV); the every-outcome control is exempt. Pick only if at least 75 validation bets and the week-bootstrap lower ROI bound exceeds zero; otherwise abstain. Closing replay uses the same tickets at the same named bookmaker, never retuning based on the close. Drawdown settles at day granularity because fixture settlement times are not universal.
- Actions separates synthetic smoke, validation, one-time official holdout, and aggregate-only republication. A public tag locks the single official run before score calculation. Re-publishing is not another experiment. A code/data mismatch invalidates the freeze. Optional current data need 50+ completed matches per league; baseline audit has eligible-match coverage rather than imputing prices.
- Report decision rule is deliberately conservative: evidence requires the ensemble's paired log loss and Brier intervals to favor it and the validation-selected betting rule to have positive lower bounds for ROI and matched same-book CLV. The poor-calibration diagnostic is ECE >6% plus failure to beat the league prior on log loss in both priced markets. Marginal, overlapping, or absent evidence is not a case for betting.
- The smoke test includes a full tiny-fixture run with a temporary Git commit for the freeze, a holdout absent until after freeze, and checks for altered training bytes and prohibited overwrite. It never creates a project release. Packages pinned by requirements are included in the model-version digest.
